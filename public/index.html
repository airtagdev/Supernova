WHAT'S NEW0.1.24

Changelog

The latest additions and improvements to Supernova.

  • Mario games

    Five Mario World games now open in Supernova's built-in SNES player using archives hosted by SMW Games.

  • No local files

    Games launch directly without asking users to select a ROM from their device.

  • Reliable startup

    The loading screen now stays visible until the SNES core actually starts the game.

  • Renderer fallback

    Mario games use the stable legacy renderer and ignore stale emulator settings.

  • Clear errors

    A failed or stalled launch now shows the emulator's error instead of an empty gray screen.
